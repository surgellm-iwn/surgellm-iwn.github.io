SURGeLLM

Rethinking multi-task evaluation through task-aware feature gating with class-balanced normalization

Abstract

Fine-tuned encoders deployed across heterogeneous NLP tasks face three compounding problems: mismatched inductive biases, class-imbalance corruption of feature statistics, and no mechanism to condition attention on external lexical knowledge.

We introduce SURGeLLM, a unified transformer framework that addresses each with a dedicated lightweight module: a surgical feature gate (a learned per-dimension sigmoid over curated lexical indicators and [CLS], which provably degenerates to identity when features are uninformative), task-conditioned prefix tokens (quantized feature values and task identity prepended to every input), and Instance-Weighted Normalization (IWN, which removes class-prior bias from gate statistics). We prove an excess-risk bound linking gate benefit to surgical feature alignment.

Across four tasks — SST-2, multi-hop retrieval, LLM-prompt attribution, and authorship detection — covering 17,830 examples and eleven model variants over three seeds, the IWN variant achieves macro-F1 0.940 (+0.034 over the strongest non-IWN variant; +0.036 over the RoBERTa baseline; +0.130 on authorship detection). A random-vocabulary control (−0.028 avg. F1) confirms gains are lexical, not parametric. Code, vocabularies, and a 99.5%-recovery auto-extraction recipe are released.

What this paper contributes

Framework

A unified multi-task encoder with per-dimension feature gates, task-conditioned prefix tokens, and IWN. Plug-compatible with any HuggingFace encoder; ~1.2M added parameters, about 1% of RoBERTa-base.

Theory

An excess-risk bound (Theorem 1) linking gate benefit to surgical feature alignment ρk, and a degeneracy result (Proposition 2) proving the gate is safe when features carry no signal.

Empirics

Eleven variants over four encoder backbones plus T5-base, three seeds, four-part vocabulary sensitivity study, and a random-vocabulary control that separates lexical content from added capacity.

Method

Four modules, one encoder

Let T = {t1, …, t4} be a fixed task set, each with label space Ytk. We fit a single model fθ: X × T → ∪k Ytk minimizing the multi-task empirical risk:

L(θ) = Σk=1..|T| wk|Dk| Σ(x,y,tk) ∈ Dk ℓ(fθ(x, tk), y)
(1)

with cross-entropy loss ℓ and wk = 1 throughout, relying on per-task batch sampling for balance. The encoder, the feature projection, the gate matrices, the task-embedding matrix, and the prefix embeddings are shared; only the four two-layer classification heads are task-specific. Shared parameters are over 99% of the total, which is what makes the multi-task framing meaningful in the MT-DNN sense.

Surgical feature extraction

For each of ten case-insensitive indicator groups vj, the count feature is the number of group members present in the lowercased text, with prefix matching for inflectional families (oscillat* matches oscillation, oscillates, oscillating):

sj = Σw ∈ vj 1[ w ∈ x̃ ],   j = 1, …, 10
(4)

Six surface features are appended: word count, mean word length, sentence count, question-mark count, exclamation-mark count, and a binary digit-presence indicator. Crucially, all sixteen are computed on the full untruncated text, while the encoder sees at most 96–128 tokens. Global statistics destroyed by truncation cannot be recovered from a partial view — this is the deterministic, lossless side channel the gate consumes.

The gate, in three steps

s′ = ReLU(Ws s + bs),   Ws ∈ ℝd×16
(5)
g = σ( Wg [ h̃ ; s′ ] + bg ),   Wg ∈ ℝd×2d
(6)
ĥ = LN( g ⊙ h̃ + (1 − g) ⊙ s′ )
(7)

Sigmoid, not softmax

Sigmoid lets each dimension take any value in (0,1) independently. Softmax would impose a unit budget across dimensions — a competitive constraint that makes no sense for dimension-wise modality fusion.

Per-dimension, not scalar

A scalar gate forces every hidden dimension to use the same modality mix. Too coarse when some dimensions encode lexical surface and others encode semantic content.

LayerNorm after fusion

Re-normalizes the fused vector back to the statistical regime of the unfused encoder output, so downstream layers are not surprised by a mean/variance shift.

The central result

Instance-Weighted Normalization

Before projection, the feature vector is standardized using statistics from the training partition. On a skewed corpus, those statistics belong almost entirely to the majority class.

Under global standardization, the mean is a prior-weighted mixture that collapses onto the majority profile as the skew grows:

ŝ(x) = ( s(x) − s̄k ) / ( σk + ε )
(8)
s̄k = Σc πc s̄c,k  →  s̄c⋆,k   as  πc⋆ → 1
(9)

The gate is then fed a measurement of deviation from the majority profile. Majority instances sit near the origin and look unremarkable; minority instances — the ones that decide macro-F1 — sit far out and look like outliers. IWN replaces the marginal statistics with an unweighted average over per-class statistics:

s̄balk = 1nc,k Σc=1..nc,k s̄c,k,     σbalk = 1nc,k Σc=1..nc,k σc,k
(10)
s̃(x) = ( s(x) − s̄balk ) / ( σbalk + ε )
(11)

At π = 0.903 — the raw 9.3:1 skew of the HumLLM corpus — the majority class sits at −0.19 and the minority at +1.81. That asymmetry is what the gate learns to fuse against.

What IWN actually fixes

Without IWN, the gate's per-class precision and recall on D4 come apart: LLM recall 0.63 against human recall 0.79. The model is biased toward predicting "human" because standardization has shifted the gate's input distribution toward the majority class. IWN symmetrizes the per-class statistics and both classes converge to ≈ 0.89.

Parameter-free

No new learnable parameters. Only the normalization constants change.

Test-time class-agnostic

The balanced statistics are computed once from training labels and applied at inference with no class information required.

Free on balanced data

When πc = 1/nc, the balanced and marginal estimators coincide up to the weighted/unweighted variance difference. IWN is a strict generalization that costs nothing in the balanced regime.

Compositional

Orthogonal to loss-side and sampling-side remedies — focal loss, class-balanced re-weighting, oversampling. We report IWN-only results for clarity.

Datasets

Four tasks chosen to interfere

Near-isotropic benchmarks do not expose destructive interference. We study the hard case: a single encoder handling movie-review sentiment, multi-hop retrieval QA, LLM-prompt attribution, and human/LLM authorship — tasks that share a backbone but draw on largely disjoint surface signals. All corpora use stratified 70/15/15 splits, label reindexing, and training-only computation of the normalization statistics.

D1 — SST-2

Binary movie-review sentiment. Standard GLUE training split (67,349), official validation set (872) as our test set, with a stratified 10% internal validation slice; capped at 7,666 for parity. Chosen because it is non-saturated on base-scale encoders (87–94% published accuracy) and exercises the polarity vocabulary the gate can act on.

D2 — HotPotQA

Multi-hop QA. Input is [Q] q [CTX] c:300; the binary label collapses the three-tier difficulty annotation (easy → 0, medium/hard → 1). Attribution phrases such as according to and the article reports are rare in questions and frequent in contexts, giving the retrieval group a clean discriminative signal.

D3 — LLM-7

14,877 essays under seven prompt conditions, stratified-capped to 3,164. Probes the llm_stat, llm_formal, and llm_list groups on longer, prompt-structured text.

D4 — HumLLM

5,000 balanced examples sampled from a 788,922-text corpus with 9.3:1 original skew. The hardest task in the suite — base models stay under 0.77 macro-F1 without IWN — and where IWN yields its largest gain.

Experimental setup

How everything was trained

Backbones

  • DistilBERT-base-uncased (66M)
  • BERT-base-uncased (110M)
  • RoBERTa-base (125M)
  • ALBERT-base-v2 (11M)
  • T5-base (220M), as a text-to-text comparison

Optimization

AdamW (λ = 0.01, β1 = 0.9, β2 = 0.999, ε = 10−8), 6% linear warmup then decay, gradients clipped at 1.0. Learning rates: 2×10−5 for Baseline and SURGeLLM-S, 1.5×10−5 for SURGeLLM-G/FULL/IWN, 3×10−4 for T5.

Hardware and budget

2× NVIDIA T4 (16 GB), FP16 via Accelerate, effective batch size 32 through accumulation. Pre-tokenization caching (chunk size 2,048) gives roughly a 25% speedup. Early stopping with patience 2 on validation macro-F1. Full reproduction is about 38 GPU-hours.

Statistics

All results are mean ± SD over seeds {0, 1, 2}. Significance is paired Welch t-tests with Benjamini–Hochberg correction at FDR = 0.05 over 4 × 4 task-variant comparisons, plus 95% bootstrap confidence intervals (B = 2,000). Reported metrics: accuracy, macro-F1, precision, recall, ROC-AUC.

Main results

Eleven variants, four tasks, three seeds

D1 is non-saturated — the F1 spread across variants is 0.901–0.937 — so aggregate averages reflect genuine differences rather than ceiling effects. SURGeLLM-IWN-RoBERTa is the top model at 0.940 average F1, ahead of the strongest non-IWN variant by +0.034 and the RoBERTa baseline by +0.036. The improvement is driven almost entirely by D4: +0.130 over baseline, which fully offsets the gate-induced drop seen without IWN.

Statistical significance

Why text-to-text does not dominate

T5-base trains in 412s against 233s for Baseline-RoBERTa (a 1.77× wall-clock penalty), carries 220M parameters against 125M (a 1.76× parameter penalty), and still trails Baseline-RoBERTa by 0.007 avg. F1 and SURGeLLM-IWN-RoBERTa by 0.043. Text-to-text framing is most powerful when tasks share a unifying linguistic structure; our four tasks are structurally heterogeneous, and T5's encoder-decoder must allocate capacity to a decoding side that classification does not need.

Ablations

Reading the components apart

The progression G → FULL → IWN on RoBERTa tells the cleanest story. The prefix alone is mildly beneficial (+0.002). Adding the gate without IWN is harmful (−0.015 average, dominated by D4's −0.051). Adding IWN reverses the regression and exceeds it (+0.036). The BERT rows show the same pattern.

Isolating IWN

Training dynamics

SURGeLLM models start from a higher initial loss (≈ 1.7–2.1) because the encoder must simultaneously become useful for four heterogeneous tasks and coordinate with the gate and prefix. They converge to comparable validation F1 within 4–5 epochs. Early stopping fires at epoch 4 for SURGeLLM-FULL-RoBERTa and SURGeLLM-G-RoBERTa, saving roughly one epoch (≈ 325s) with no test-F1 regression.

Vocabulary sensitivity

Is the curated vocabulary doing the work?

Four complementary studies on SURGeLLM-G-RoBERTa, all over three seeds. The question behind them: are the gains lexical, or are they the extra parameters the feature channel happens to bring along?

Why surface features survive the encoder

Truncation. The encoder receives at most 96–128 tokens. Total word count and total exclamation count are computed on the full document and carry information unavailable from a partial view.

Distributional shift. Even without truncation, the [CLS] representation is optimized for masked-token prediction and need not preserve precise count statistics. The surgical channel supplies them deterministically and losslessly.

Per-group leave-one-out

Transfer without manual curation

For a new language or domain: extract candidate indicator words by class-conditional log-odds with an informative Dirichlet prior on each task's training set, rank by absolute log-odds and keep the top K = 50 per class, embed the union with SBERT, then k-means into ten clusters. Cluster membership becomes the indicator groups; surface features are unchanged. This recovers 0.903 against 0.906 for manual curation.

Efficiency

What the gate costs

The gate adds 2d² + d ≈ 1.18M parameters, the feature projection ≈ 12.5K, the task embedding ≈ 3K — about 1.2M total, roughly 1% of RoBERTa-base. Asymptotically the surgical components are Θ(d²) against the encoder's Θ(L·d²), negligible for L ≫ 1. The real cost is wall-clock: about 100s on 2×T4 (233s → 332s), a 43% overhead driven mainly by extended training and prefix tokenization.

Theory

When the gate helps, and why it cannot hurt

Definition 1 — Surgical feature alignment

For task tk and input distribution Ptk, the alignment ρk is the expected absolute inner product between the projected feature vector and the gradient of the conditional log-likelihood at the fused representation:

ρk = 𝔼(x,y) ~ Ptk [ | ⟨ s′(x), ∇ĥ log p(y | ĥ) ⟩ | ]
(15)

When ρk is high, perturbing ĥ along s′ moves the log-likelihood a lot, so s′ encodes information about y. When ρk = 0, s′ is orthogonal in expectation to the score function and carries no task-relevant signal.

Theorem 1 — Gate approximation bound

Let f⋆ be the Bayes-optimal classifier for task tk and fθ a SURGeLLM classifier from ERM on Nk examples. If the encoder is Lφ-Lipschitz, the head map Lhead-Lipschitz, and the loss ρ-Lipschitz in its first argument, then with probability at least 1 − δ:

R(fθ) − R(f⋆) ≤ C√Nk  +  λmax(Wg⊤Wg)2 ‖ s′ − s⋆ ‖2
(16)

The first term is standard: more data shrinks the generalization gap. The second is the novel piece — small when the projected feature vector is close to its oracle s⋆, large when the gate matrix has high spectral norm. Highly aligned tasks benefit more, because s′ then carries useful signal that even a modest Ws approximates well.

Proposition 2 — Degeneracy under zero alignment

If ρk = 0, then at any local minimum of the regularized loss with weight decay λ > 0: ‖Ws‖ → 0, hence s′(x) → 0, hence gi⋆ → 1 for every dimension, and the fusion collapses to ĥ → LN(h̃). The expected gradient vanishes, the update reduces to pure exponential decay Ws ← (1 − λη)Ws, and to minimize loss the gate routes all signal through h̃.

Corollary 3 — Safety of adding the gate

For any task with ρk = 0, adding the surgical gate cannot increase the minimum achievable empirical risk. The gate either strictly improves (ρk > 0) or degenerates to identity (ρk = 0).

Empirical caveat — the imbalance loophole

Corollary 3 assumes ρk accurately captures gradient-feature alignment under the distribution the gate actually sees. Under severe class skew, Eq. 8 feeds the gate prior-contaminated features, and the effective ρk measured on that contaminated distribution can be misleadingly low even when the underlying feature signal is informative.

This is precisely the failure mode observed on D4 without IWN — and it is why the safety guarantee did not save us. IWN restores the conditions of Proposition 2 on imbalanced data.

Failure analysis and limitations

Where this breaks

We manually inspected 50 misclassified examples per task on SURGeLLM-IWN-RoBERTa. The failures are diagnostic — they mark the boundary of the gate's utility rather than random error.

D1 — SST-2

Negation scope (not bad), sarcasm, and mixed-sentiment reviews. The gate cannot help: polarity vocabulary fires on both sides of the decision.

D2 — HotPotQA

Questions with implicit multi-hop chains and no explicit attribution cues. The retrieval group has nothing to fire on.

D3 — LLM-7

Human essays that mimic LLM scaffolding in a formal academic register, and LLM essays edited by humans to strip enumerative markers.

D4 — HumLLM

After IWN, the residual failures concentrate on short texts (< 30 words), where surgical-feature counts are unreliable. This motivates length-conditional gating.

Stated limitations

  • Experiments are English-only; the multilingual result in Table 11 is preliminary and small-scale.
  • Coverage is base-scale encoders, 11M–220M parameters. Extension to LLaMA-class encoders is explicit future work, and we expect absolute gains to shrink as encoder capacity saturates ρk — though the do-no-harm guarantee holds at all scales.
  • The bound is standard Rademacher complexity and may be loose for modern transformers. PAC-Bayes or NTK tightening is open.
  • Evaluation is four heterogeneous tasks by design, not the full GLUE/SuperGLUE suite. That is the point of the study, but it does limit external comparability.
  • IWN is reported alone, without composition against focal loss, class-balanced re-weighting, or oversampling. Whether the gains are additive is untested.
